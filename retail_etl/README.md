# Proyecto ETL Retail

## Objetivo

Integrar información proveniente de MySQL, MongoDB y archivos CSV mediante un proceso ETL automatizado.

## Fuentes de Datos

- MySQL: Ventas históricas
- MongoDB: Perfiles de usuarios
- CSV: Inventario

## Transformaciones

- Limpieza de nulos
- Eliminación de duplicados
- Normalización de fechas
- Escalamiento Min-Max
- Segmentación de clientes

## Analítica

- PCA (3 componentes principales)
- Boxplot de montos
- Scatter Plot PCA
